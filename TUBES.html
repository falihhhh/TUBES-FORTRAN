Analisis Perbandingan Kecepatan Algoritma Bubble Sort, Selection Sort, dan Insertion Sort pada Berbagai Ukuran dan Kondisi Data

Ketiga algoritma pengurutan ini sama-sama O(n²) secara teori, tetapi apakah kecepatannya benar-benar sama? Kami mengukurnya langsung pada data berukuran 100 sampai 5.000 elemen dengan tiga kondisi data. Website ini menampilkan hasil pengujian, grafik, dan demo interaktif yang bisa kamu coba sendiri.

Analisis Pertumbuhan Waktu Eksekusi:

  • Pertumbuhan Kuadratik O(n²): Kenaikan ukuran data 5x lipat (dari 1.000 ke 5.000) meningkatkan waktu eksekusi sekitar 27–30 kali lipat (Bubble Sort 30,1x, Selection Sort 26,9x, Insertion Sort 29,9x), konsisten dengan prediksi kuadratik 5² = 25.
  • Bubble Sort Paling Lambat: Pada n = 5.000, Bubble Sort membutuhkan 825,30 ms — sekitar 2,5 kali lebih lambat dari Selection Sort dan 2,3 kali lebih lambat dari Insertion Sort.
  • Selection vs Insertion Sort: Keduanya berada pada performa yang hampir setara; perbedaan di n = 5.000 masih berada dalam batas simpangan baku.

Analisis Pengaruh Kondisi Data:

  • Data Terurut: Bubble Sort (dengan penanda pertukaran) dan Insertion Sort selesai di bawah 0,2 ms karena berperilaku linier O(n) — lebih cepat >1.600x dan ~500x dibanding data acak. Selection Sort tidak terpengaruh (48,38 ms) karena tetap memindai seluruh elemen.
  • Data Terbalik: Waktu Bubble Sort naik 1,4x dan Insertion Sort naik 1,5x dari kondisi acak. Selection Sort menjadi yang tercepat (51,87 ms) karena jumlah pertukarannya paling sedikit.

Kesimpulan Hasil Pengujian

1

Pertumbuhan Kuadratik O(n²)

Pada data acak, waktu eksekusi ketiga algoritma tumbuh secara kuadratik. Bubble Sort paling lambat (2,3–2,5x lebih lama dibanding Selection dan Insertion Sort).

2

Keunggulan Linier pada Data Terurut

Pada data terurut, Bubble Sort (dengan penanda pertukaran) dan Insertion Sort berperilaku O(n) sehingga jauh lebih cepat, sedangkan Selection Sort tidak terpengaruh.

3

Selection Sort Unggul di Data Terbalik

Pada data terurut terbalik (worst case), Selection Sort menjadi algoritma tercepat karena meminimalkan operasi pertukaran antar-elemen.

4

Konsistensi dengan Analisis Teoretis

Jumlah perbandingan yang terukur konsisten dengan perkiraan teoretis, membuktikan pengukuran empiris valid untuk memverifikasi teori kompleksitas.
